# 家族ホテル共有帳

家族間で「旅行で行きたい」と思ったホテルを共有できる、シンプルなWebアプリです。

## できること

- 𝕏 / Instagram / Googleマップ / 楽天トラベル / WEBサイトなどで見つけたホテルを、リンク付きで登録
- 都道府県ごとにセグメントして一覧・絞り込み表示
- 気になった候補にハートで「いいね」
- 登録者名・メモ・登録日を表示
- 誤登録の削除

多機能にはせず、家族での共有・保存・いいねに機能を絞っています。

## 使い方

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開きます。
同じネットワーク内の家族のスマホ・PCからは `http://<このPCのIPアドレス>:3000` でアクセスできます。

データは `data/hotels.json` に保存されます（Git管理対象外）。

## 技術構成

- サーバー: Node.js + Express
- データ保存: JSONファイル（DBサーバー不要）
- フロントエンド: 素のHTML/CSS/JavaScript（ビルド不要）
